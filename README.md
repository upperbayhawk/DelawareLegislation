# Delaware Bill Outputs (ZIP Package)

This repository contains AI generated output files created using OpenAI GPT-5.2.

## Contents

- `bill_summary/`: Markdown summaries for Delaware bills.
- `downloads/`: Source PDF files used to produce summaries.

## How to Use (ZIP)

1. Download the repository ZIP from GitHub.
2. Extract the ZIP to a local folder.
3. Open `bill_summary/` to read summaries.
4. Open `downloads/` to review original bill PDFs.

## File Naming

- Summary files are named with bill identifiers and House/Senate bill numbers when available.
- PDF files are named with legislation identifiers so summaries can be matched to source documents.

## Notes

- These files are generated artifacts intended for review and research.
- These files represent a subset snapshot of the legislation available. If some bills are missing, they may not have had accessible PDF source documents at generation time.
